# 🌐 UniFlow - Student Life Planner

UniFlow is a simple and modern student life planner designed to help students manage their daily activities in one place.

## ✨ Features

- 🔐 Student Login
- 🏠 Dashboard
- 💰 Budget Planner
- 📚 Study Hours Tracker
- 🏃 Fitness Tracker
- 😴 Sleep Cycle Tracker
- 💾 Local data storage using LocalStorage
- 📱 Responsive design for desktop and mobile
